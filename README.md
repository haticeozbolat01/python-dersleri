# Python Dersleri

[haticeozbolat.com](https://haticeozbolat.com) üzerindeki sıfırdan Python serisinin not defterleri. Her dersin anlatımı blogda, kodları ve alıştırmaları burada.

## Nasıl kullanılır?

1. Aşağıdaki tablodan dersi seç ve **Colab'da Aç** düğmesine tıkla. Not defteri tarayıcında, Google Colab'da açılır; kurulum gerekmez.
2. Üst menüden **Dosya > Drive'da kopya kaydet**'i seç. Böylece çalışman kendi Google Drive'ında saklanır.
3. Hücreleri sırayla **Shift + Enter** ile çalıştır. Alıştırmaların cevapları her not defterinin sonunda.
